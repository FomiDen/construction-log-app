### 🛠 Архитектура и Технологический стек

#### **Frontend (`/client`):**
* **Стек:** React, TypeScript, Vite (сборщик)
* **Стилизация:** Tailwind CSS
* **Особенности:** Быстрый SPA-интерфейс, оптимизированный под мобильные устройства прорабов на объекте. Строгая типизация контрактов данных.

#### **Backend (`/server`):**
* **Стек:** Node.js, TypeScript, REST API
* **ORM:** Prisma (управление схемами, генерация типов и миграций)
* **Инфраструктура / БД:** PostgreSQL, запущенный в изолированном контейнере через **Docker Compose**

---

### 🚀 Реализованный функционал

1. **База данных и миграции:** Спроектирована схема данных в Prisma (`schema.prisma`), создана и применена стартовая миграция для логирования параметров: дата, тип работ, объём, единицы измерения, ФИО прораба.
2. **REST API:** Полноценный бэкенд на Node.js для обработки CRUD-операций:
   * Получение актуального списка выполненных работ из базы данных PostgreSQL.
   * Валидация и запись новых логов с объекта.
   * Удаление записей.
3. **Клиентская часть:** Интерактивная таблица-журнал с возможностью мгновенной фильтрации/сортировки записей по датам на клиенте и динамическая форма добавления записей.

---

### 📦 Инфраструктура и развертывание

Проект подготовлен к локальному деплою в один клик. Вся конфигурация базы данных инкапсулирована в Docker.
